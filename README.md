# 📌 About The Project

DenizCRM is a modern CRM application developed to improve software architecture skills while following enterprise-level development practices.

The project focuses on:

- Clean Architecture
- CQRS Pattern
- Repository Pattern
- RESTful API
- Entity Framework Core
- SQL Server
- Swagger Documentation

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/DenizDogruel82/DenizCrm.git
```

Go to project folder

```bash
cd DenizCrm
```

Restore packages

```bash
dotnet restore
```

Run project

```bash
dotnet run
```

Open Swagger

```
https://localhost:xxxx/swagger
```
